## Project Description
The **Campus Lost & Found Board** is a mobile application built with Flutter designed to help students and staff easily report, track, and recover misplaced belongings around school. Instead of relying on scattered group chats or physical bulletin boards, the app provides a centralized digital feed where campus members can connect directly to return lost items.

### Core Features
* **Post Lost/Found Items:** Users can create listings featuring an item photo, description, and location details.
* **Browse Campus Feed:** A scrollable feed displaying lost and found items across the school.
* **Claim Status:** Items can be marked as **Claimed** once returned to their rightful owner.
* **Direct Contact:** In-app messaging is excluded to keep the app lightweight; listings display the poster's contact information (email or phone number) for quick, direct coordination.
